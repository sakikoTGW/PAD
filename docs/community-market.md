# 社区资源与插件商店

下载页左栏只有三个去向：**发行号**、**插件商店**、**下载任务**。

「插件 / 终端 / 技能与工具 / 官方组件」不是多套商店，而是同一个插件商店里的分类芯片。它们共用搜索、筛选、详情和安装流程，只改变 npm 查询范围。打开商店时默认落在 **推荐**（增长榜）。

| 芯片 | 默认 npm 查询 | 用途 |
|---|---|---|
| 推荐 | （本地增长榜，非 npm search） | 增长最快的包；可按日 / 周 / 月看。 |
| 全部 | `keywords:dsh-plugin` | 扩展 DSH 能力的社区插件；安装到所选实例的 profile。 |
| 终端 | `@deepseek-harness-tui` | 终端界面、TUI 外壳与命令行交互组件。 |
| 技能与工具 | `keywords:dsh-plugin skill` | 「全部」的子集：技能、自动化与开发工具；结果可能重叠。 |
| 官方组件 | `@deepseek-ai/dsh-host` | DSH 官方宿主与运行时集成；部分包不适合直接安装。 |

- **发行号**：安装和管理 `@deepseek-ai/dsh` 本体版本。
- **下载任务**：查看本机发行号安装与插件增删改队列。

## 安装语义

商店中的安装最终作用于选中实例的 profile，复用 DSH 自己的插件命令。PAD 不维护第二套插件格式。目标实例、DSH 发行号与 profile 是否兼容，仍由 DSH 的插件管理逻辑判断。

## 自定义分类

设置 → 下载 → 社区资源可覆盖默认分类，每行格式：

```text
id|标签|npm 查询|用途说明
```

前三项必填，用途说明可留空。自定义项会作为额外芯片追加在商店页内；「推荐」始终在最前。
