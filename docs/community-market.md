# 社区资源与插件商店

下载页的「插件 / 终端 / 技能与工具 / 宿主与官方」不是四套商店。它们是同一个 npm 插件商店的四个查询货架，共用搜索、筛选、详情和安装流程，只改变 npm 查询范围。

| 货架 | 默认 npm 查询 | 用途 |
|---|---|---|
| 插件 | `keywords:dsh-plugin` | 扩展 DSH 能力的社区插件；安装到所选实例的 profile。 |
| 终端 | `@deepseek-harness-tui` | 终端界面、TUI 外壳与命令行交互组件。 |
| 技能与工具 | `keywords:dsh-plugin skill` | 提供技能、自动化流程和开发工具的插件。它是「插件」的子查询，因此结果可能重叠。 |
| 宿主与官方 | `@deepseek-ai/dsh-host` | 官方宿主、载体和运行时集成组件；用于理解或组装宿主，不代表每个包都适合直接安装。 |

「发行号」和「下载任务」不是商店货架：

- **发行号**：安装和管理 `@deepseek-ai/dsh` 本体版本。
- **下载任务**：查看本机发行号安装与插件增删改队列。

## 安装语义

商店中的安装最终作用于选中实例的 profile，复用 DSH 自己的插件命令。PAD 不维护第二套插件格式。目标实例、DSH 发行号与 profile 是否兼容，仍由 DSH 的插件管理逻辑判断。

## 自定义货架

设置 → 下载 → 社区资源可覆盖默认货架，每行格式：

```text
id|标签|npm 查询|用途说明
```

前三项必填，用途说明可留空。自定义货架仍会打开同一商店页。
